# 统一模型池 · Model Hub

DSH 本地插件 `@local/dsh-model-hub`，版本 **0.2.0**，面向 DSH 0.2.2-rc.1 及兼容版本。

**主 Agent + 全模型共享池**：汇集所有已挂载渠道的实际模型，由主 Agent 按任务挑选一个或多个子代理模型，不限于固定的 GPT＋Gemini 配对或三角色模板。当前主模型保持不变。

统一的是候选与调度选择，不是账号、额度或计费；保留真实 provider/model、原有登录和原生执行器，不复制密钥、不伪造模型。

## 使用

1. 更新后刷新现有 GUI，打开 **设置 → 统一模型池**。不需要创建组合模板。
2. 默认选择 **所有当前及以后发现的目录模型**；也可按渠道/关键词筛选并保存手选子集。保存只改候选偏好，不调用模型、不授权、不切主模型。
3. 点击 **授权池给新会话**。检查本次候选及包含既有授权的完整清单，勾选确认，再提交。目录不完整时不能授权全池，可选择明确可见的子集。
4. **新建顶级会话**，继续用你选定的主模型。旧会话及其子会话不会获得新增模型权限。
5. 例如告诉主 Agent：**“使用模型池完成这项任务，按需要选择合适的子代理模型，不要拘泥固定角色。”**

插件通过公共 systemPrompt 服务提供简短、按工具可见性生效的选模指引。主 Agent 查询池、核对当前原生授权，再调用 native subagent；它不会仅因模型在池中就把全部模型运行一遍。完整自定义 prompt 可能不显示额外 section，工具描述仍提供同样指引。

DeepSeek 等新渠道仍在原有提供者插件配置。成功挂载后自动成为 all 模式的候选，**不会自动获得调用授权**；用户再次确认后，仅随后新建的会话获得新清单。

## 主 Agent 的只读接口

- `model_hub_pool()`：池涉及的渠道概览，只读 provider registry，不查询模型目录。
- `model_hub_pool({view:"models", limit:25})`：跨渠道分页模型目录。
- `model_hub_pool({query:"flash"})`：跨渠道关键词搜索。
- `model_hub_pool({provider:"实际渠道ID"})`：该渠道的池模型。
- `model_hub_pool({provider:"实际渠道ID", model:"实际模型ID"})`：精确详情及该模型的真实思考档位。
- `model_hub_routes()`：可选旧角色模板；不是调度上限，也不要求先有活动模板。

分页默认 25、最大 100。目录跨次查询可能变化；错误摘要最多返回 25 项，并给出总数与截断标志。单渠道超过 20000 条广告模型时明确报告目录限制，不假装返回完整目录。

只有 SDK 已声明的字段才会展示：例如输入模态、上下文长度、模型原生 effort ID。默认输出 token cap 不是理论最大输出；不猜价格、速度、质量或健康状态。广告目录不含全部详情，精确能力按需查询，避免逐模型重复 preflight。

**目录可见 ≠ 当前会话授权 ≠ 额度充足 ≠ 实际调用成功。** 模型最终必须位于池与当前 `list_subagent_models` 的交集中；实际执行仍走原生 `subagent`，保持原有深度、并发、工具权限、取消和任务生命周期。

## 安全、状态与兼容

- 两个工具均不推理、不启动 Agent、不写授权。模型目录/详情由原有 adapter 提供，可能在其内部解析凭据并做元数据 I/O；插件不直接读取或输出凭据。取消会停止本插件等待，不能保证中止 adapter 共享后台刷新。
- 目录文本是来源数据，不是指令。输出采用字段白名单，不包含 adapter/profile、headers、baseURL、auth 或原始异常堆栈。
- 不静默换供应商、替换失效档位或启用额外付费。选模本身不改变各渠道计费规则。
- 单一 volatile state 原子保存，规范形状为 `pool / activePresetId / presets`。池支持 all 或 selected；selected 最多 4096 个精确身份，不绑定角色/固定 effort。all 不受该手选存储上限约束。
- 未知字段、重复身份/模板 ID、悬空活动 ID、无效角色与控制符均拒绝。官方 Settings CAS 冲突时保留草稿，不自动重试或覆盖。
- 旧 state 缺 pool 时只在投影中兼容为 all/[]，不自动写迁移或授权。池与模板编辑互相保留，旧模板界面默认折叠。
- 授权先刷新目录和设置，再展示精确候选与原生 union。确认后再次刷新两者，发现候选增减或设置变更就撤销旧确认；不把未展示的新模型夹带进清单。最终仅对已展示的原生授权清单做一次 CAS，不冒充跨 namespace 原子事务。
- 移出候选池、禁用或卸载插件都不会撤销原生授权；需要撤权请去原生子代理模型设置。变更仍仅影响新会话。
- 不调用会改变全局默认的 `session.selectModel`；更换主模型由用户手动操作。

## 更新与回退

0.1.0 曾因回调闭包与 Host 二次 Schema 序列化丢失回调而使设置页一直加载。0.1.1 的自包含、可重复序列化纯校验工厂保留至本版；没有修改 SDK 或强行将 loading 当 ready。

安全回退方式是先禁用此插件，原有账号、会话、Antigravity App 与 native subagent 不受影响。**不要直接用 0.1.1 覆盖已含 pool 的配置**：旧版严格 schema 不支持该字段。确需降级，应先通过官方配置编辑器备份并迁移插件自有 state，再安装旧包；不要修改授权快照或账号数据。

## 验证

**104 项离线测试全部通过，0 跳过、0 失败**：17 core、19 pool、8 Host、48 UI、12 真实浏览器设置桥接。包括多模型、多渠道、动态发现、迁移、跨模板保存、4096 条错误限界、思考档位、并发取消、两阶段授权、延迟设置通知、原生快照以及反复 Schema 序列化。

```sh
ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' \
  --test test/*.test.js test/*.test.cjs
```

普通 Node 可以跑纯逻辑/UI 测试，但不能遍历应用 ASAR，会明确跳过原生 Host/桥接用例，不应把 skip 当通过。桥接使用实际 Host SettingsForms 与浏览器 Schema/Form/Controller，但传输和持久化为合成内存夹具；**这不是实际 GUI DOM/CSP 或真实账户推理验收**。

**新授权会话中的 Codex→Gemini 3.8 Flash 原生子代理及只读工具回合仍待验证**。先前直接 API 成功不能冒充此项通过；Argon 验证保持暂停。
