# 输入框额度徽标

版本：0.1.0-rc.5.quota.1（2026-11-08）。

在 Codex 同款 `conversation.input.right` 公共插槽，显示当前 Antigravity 模型对应的 **5h + 周**剩余额度。Gemini 使用 Gemini Models 组；Claude/GPT 使用其共享组。两个周期同时可见，切模型只重选已有快照，不改模型/账号/授权；非 Antigravity 模型不显示本徽标。

点徽标展开详情，可看重置时间、最后更新时间与手动刷新。页面可见且有对应模型消费者时，每60秒取数；本地15秒更新时钟；隐藏页面暂停轮询，离开所有对应模型后清除缓存与计时器。并发请求合并，30秒客户端等待上限；卸载、重连、登录/登出及模型设置操作隔离旧返回。客户端取消是忽略迟到结果，不能撤销宿主已开始的共享元数据请求。

只调用原有、已鉴权的 `antiGravityAuth.describe`，不新增HTTP路由、不读取模型凭据、不发起推理。使用服务明确提供的 `5h` / `weekly`，不会拿单模型 quotaInfo 或重置时间推测周期。真实0显示0%，缺失/非法/多义窗口显示 --；过期或刷新失败有标记，绝不按倒计时自动恢复100%。

## 构建与验证

本包部分 TypeScript 源码与既有预构建设置页/模型开关并不同步，不能整体重编译替换。额度徽标采用纯 JavaScript overlay：保留预构建客户端 facade，嵌入 `src/client/composer-quota.js`、扩展 locale、声明 modelDirectories 依赖并注册插槽。所需运行文件与离线测试随包提供；额度徽标本身不改动 OAuth、额度接口、原生上下文/流或 Typert 契约。

38项离线检查覆盖选择器、缓存/超时/生命周期、显式MOCK React组件、完整发布facade挂载、发布清单及基线哈希；另外保留原生上下文/流回归。MOCK与facade测试不等于实际浏览器视觉验收。

部署后应在已登录的 DSH GUI 刷新，切换 Gemini 与 Claude，确认两项徽标及详情。视觉验收须使用安装者本人授权的浏览器会话；不能通过读取浏览器登录资料或绕过认证进行验证。离线测试不代表真实账号、实际额度响应或模型推理已验收。
